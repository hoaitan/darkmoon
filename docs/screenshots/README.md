# Screenshots

A small curated set of images from a `yarn capture` run, kept here so the PR that introduced the
extension's UI could show it. These are illustrative, not a source of truth — per
[CONTRIBUTING.md](../../CONTRIBUTING.md), the actual rule is that every PR with a UI/UX change
runs `yarn capture` fresh and attaches current output from `playwright/screenshots/` (which is
gitignored, regenerated per run, and not meant to accumulate in the repo).
